# Move to Heal

One-page team website for Move to Heal, an AI-powered home rehabilitation app that checks your exercise form.
Youth Team Winner, Global AI Hackathon 2025.

Live: https://nsumia.github.io/move-to-heal/

Static HTML and CSS, no build step. Run `tools/run_tests.sh` for the checks (HTML, links, banned text, no glow CSS, page weight, required texts, screenshots).

Photo and quote: MIT App Inventor Winners Spotlight (https://www.appinventor.org/news/winners-spotlight-2026). Built with MIT App Inventor. Not affiliated with or endorsed by MIT.
